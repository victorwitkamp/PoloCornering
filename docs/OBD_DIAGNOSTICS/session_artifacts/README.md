# Session Artifacts

This directory stores retained raw JSON/TXT evidence from live Polo/PQ25 car
sessions. It is the evidence archive for `docs/OBD_DIAGNOSTICS`.

New live-run output is written by default to `obd-on-pc/logs/`. Move only
evidence worth keeping long term into this directory, and reference it from
`docs/OBD_DIAGNOSTICS/pq25_evidence_matrix.md`.
